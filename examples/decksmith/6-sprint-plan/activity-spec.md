# activity specs — the working (Sprint 1)

_Source of truth for the **Go-to-market → Activities** blocks of `6-sprint-plan.md#must` / `#backlog`.
Each go-to-market item at feature altitude: Description · Scope · Business value (the `M-…`/`H-…` it
serves) · Audience value · Links (the `H-…` tested / `M-…` moved / `B-…` bundle it launches) · Owner ·
Estimate. Ranking/line from `prioritization-sprint-plan`._

## Must

### A-1 · Founder-community design-partner recruitment — runs bundles B-01 / B-05
- **Description:** a founder-led post + DM sequence in the warm design community inviting S1 makers
  (agencies on deadline · freelance designers) to become **design partners** — the `H-011` channel
  test.
- **Scope:** draft the founder post (the B-01/B-05 message); pick the warm audience segment; publish +
  DM outreach; capture qualified sign-ups via the T-1 landing/waitlist; log a blended-CAC proxy
  (founder time + any spend).
- **Business value:** tests `H-011` (founder-community reaches S1 at PLG-viable CAC); moves `M-cac`
  (proxy) and seeds `M-activated`. Target for the period: ≥8 recruited, ≥6 activated (`5#goal-targets`).
- **Audience value:** early access + founder attention + influence over a tool built for *their* exact
  restyle-tax pain — not spam.
- **Links:** `H-011` · `M-cac`/`M-activated` · bundles **B-01** (agency deadline) + **B-05** (freelance
  designer) · runs on the landing surface (T-1).
- **Owner:** founder ⚙️.
- **Estimate:** ~0.3 FTE across the sprint (the founder's g2m capacity).

## Backlog

### A-2 · WTP price-talk script + prep — links `H-010` · bundle B-01
- **Description:** prepare and (once partners exist) run a **price-talk** presenting the premium price
  to recruited partners — the `H-010` monetisation proxy (`5#hypotheses-to-test`).
- **Scope:** draft the price-talk script + premium price framing; schedule with recruited partners;
  record willingness on the qualified-action scale (price talk / pre-pay intent = strong).
- **Business value:** tests `H-010` via the price-talk proxy; informs `M-paid-conv`.
- **Audience value:** partners get to shape pricing before it's set.
- **Links:** `H-010` · `M-paid-conv` (proxy) · bundle **B-01**.
- **Owner:** acting PO / founder ⚙️.
- **Estimate:** ~0.1 FTE (rides on A-1's recruited partners — fires later in the period).
