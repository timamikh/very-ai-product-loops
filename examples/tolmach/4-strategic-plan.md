## Юнит-экономика {#unit-economics}
<!-- tool: unit-economics -->

_Compute — внешние API (⚙️ гибрид, старт на внешних) → «честный/с амортизацией» базис **не
применяется** (только own-GPU); один operational-базис. Все числа ⚙️ плейсхолдеры, WTP/COGS — гипотезы._

| Метрика <!--c:metric--> | Operational <!--c:operational--> | Честный (own-compute only) <!--c:honest--> | Допущения <!--c:assumptions--> |
|--------|-------------|------------------------------------------------------------|-------------|
| Revenue per payer ($/мес) | ~$10 | n/a (внешний API) | тир better; якорь WTP `H-015` [assumption] |
| COGS per payer ($/мес) | ~$2–6 | n/a | инференс real-time, тяжелее voice-clone; линеен по минутам [assumption: правило аллокации по минутам] |
| Contribution ($/мес · %) | ~$4–8 · ~40–70% | n/a | чувствителен к COGS voice-clone — может уйти к нулю [assumption] |
| CAC (по каналу) | ~$15–40 | n/a | нишевые каналы дешевле платного; данных нет ⚙️ |
| Payback | ~3–8 мес | n/a | CAC / contribution [assumption] |
| LTV | ~$40–80 (churn 5/10/15%/мес ⚙️) | n/a | когорт нет → LTV = contribution / churn (`#retention`) [assumption] |

## Финансовая модель {#financial-model}
<!-- tool: financial-model -->

_Простая проекция на драйверах метрик-дерева; churn как ось сценариев._

| Драйвер <!--c:driver--> | База <!--c:base--> | Допущение <!--c:assumption--> | Уверенность <!--c:conf--> |
|--------|------|------------|------------|
| Новые пары / мес | ⚙️ нишевые каналы, малый старт | число — тест шага 5 | [assumption] |
| Активация W1 (`M-activation`) | ⚙️ ~40% | гейтируется `H-001` | [assumption] |
| Конверсия free→paid (`M-free-to-paid`) | ⚙️ ~3–5% | `H-018` | [assumption] |
| ARPU | ~$10/мес | `H-015` | [assumption] |
| Churn (мес) | сценарии 5/10/15% ⚙️ | когорт нет | [assumption] |

- Потолок мощности: ⚙️ **не инфра, а COGS** — compute линеен по минутам (внешние API, нет экономии
  масштаба) → рост сжимает маржу, если COGS не падает (`R-012`).
- Сценарии: база (актив.~40%, free→paid~4%, churn~10%, COGS~$4 → LTV/CAC ~2×, маргинально) ·
  оптимистичный (~55%/~6%/~5%/~$2 → ~4×, жизнеспособно) · консервативный (~25%/~2%/~15%/~$6 → <1.5×,
  нежизнеспособно). Ключевые дельты — осуществимость→активация и COGS voice-clone. [assumption]
