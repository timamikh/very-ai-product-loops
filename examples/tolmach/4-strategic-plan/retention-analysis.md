## Петля вовлечения (гипотеза удержанного ядра)

⚙️ trigger → action → reward → investment для пары:
- **Trigger:** пара хочет поговорить о чём-то важном/эмоциональном на разных языках.
- **Action:** живой разговор через Толмач голосом партнёра.
- **Reward:** услышали *друг друга*, разговор не сорвался, эмоция сохранена (дифференциатор M2).
- **Investment:** голосовой профиль настроен, привычка/ритуал ежедневного разговора → возврат.
[assumption]

- **Точка оттока (гипотеза):** первый *неуспешный* разговор (задержка/срыв/робо-голос) на реальной
  речи → пара возвращается к бесплатному субституту. Значит удержание гейтируется осуществимостью
  (`H-001`) сильнее, чем «фичами». [assumption]
- **Путь воскрешения:** триггерное письмо/пуш «давно не было живого разговора» (product-surface #7).
