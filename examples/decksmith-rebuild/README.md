# Decksmith — независимый rebuild (2026-08-14)

Полный повторный проход фреймворка **по брифу**, сделанный агентом автономно (без человека у сессии), рядом с
курированным `examples/decksmith/` — чтобы их можно было сравнить и чтобы на живом прогоне найти слабые места
процесса.

## Что это

- **Вход (переиспользован как «бриф»):** `sources/founder-brief.md` + `sources/market-research.md` (захваченные
  источники — их я не пересочинял; всё ниже по потоку собрано заново).
- **Выход (собран с нуля):** артефакты шагов 1–6, worklog-слой для шагов 1–4, три реестра
  (`registers/`), `config.yaml`, `state.yaml`.
- **Главный побочный продукт:** [`WEAKNESSES.md`](WEAKNESSES.md) — приоритезированный разбор слабых мест
  процесса, найденных прямо на прогоне, + сверка с эталоном (валидация воспроизводимости).

## Честные ограничения прогона (by design, не недоделка)

1. **Ни одна секция не подтверждена.** `theses` не самоподписывает `confirmed:`; человека у сессии нет →
   все секции в статусе *pending*, все 41 гейт-строка в `state.yaml` = `open`. Это потолок автономности (W1).
2. **Шаги 1–4 — с worklog-слоем; шаги 5–6 — artifact-direct** (как эталон: worklog-папок нет). Причины — в
   WEAKNESSES W8/W10.
3. **retention / unit-economics / financial-model** на шаге 4 — `deferred`: нет продукта на рынке, нет когорт,
   нет actuals. Метрики определены, но `not-instrumented`; `metrics.csv` пуст.
4. `metrics.csv` написан по **канону REGISTERS (10 колонок)**, а не по 8-колоночному эталону — намеренно, см. W4.

## Проверки

`python3 tools/lint.py examples/decksmith-rebuild` → **0 error, 0 warning**.

## Как сравнить с эталоном

`examples/decksmith/` — курированный, многосессионный, с подтверждениями и делайверблами. Этот rebuild —
однопроходный автономный. Совпадение сути (сегмент, риск-№1, клин нативной точности, дерево метрик, риски) при
законных расхождениях (SAM, нумерация гипотез) описано в конце `WEAKNESSES.md`.
