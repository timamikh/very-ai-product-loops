# Hypothesis register

Every bet/assumption the loops carry, born once and refined downward, results flowing back up.
Never re-authored per step; never deleted (a refuted bet stays). Schema: `process/REGISTERS.md`
in the vendored framework. One `type` per row; cross-cutting themes go in `tags`;
`signal`/`decision` fill only after a test readout.
