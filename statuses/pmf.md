# Status: pmf

First clients are here and the product has a plausible path to profit. The goal is to
**validate repeatable value and monetization** so the product can be scaled with confidence.

Priority goals center on retention/repeat usage, willingness to pay, and unit economics
turning viable. Product/usage data now exists, so goals become measurable against the metric
tree.

**Effect on the loops:** the metric tree (4) firms up around a North Star for value +
monetization; tactical goals (5) target retention and payment nodes; hypotheses shift from
"is there demand" to "does value repeat and can we charge".
