## Job-to-be-Done

**Job statement.** _When_ <circumstance / trigger>, _I want to_ <make this progress>, _so that_
<outcome / motivation>. [assumption]

_The middle clause is progress, not a product or feature._

**Four forces (switch from the current way → the new one)**

| Force | Direction | For this job | Confidence |
|-------|-----------|--------------|------------|
| Push | away from status quo | what makes the current way unacceptable | [assumption] |
| Pull | toward the new solution | what attracts them to the new way | [assumption] |
| Anxiety | resists the new solution | fears/uncertainty about switching | [assumption] |
| Habit / inertia | resists leaving the status quo | attachment to the existing way | [assumption] |

_Progress happens only when **push + pull > anxiety + habit**._

**Desired outcomes (ODI).** Measurable directions the customer judges success by — minimize /
increase the time / likelihood / effort of …

- … [assumption]
